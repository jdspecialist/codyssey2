\# 퀴즈 게임 예외 처리 및 안전 종료 테스트 결과



\## 1. 개선 내용

\- 기존 구조에서는 `KeyboardInterrupt(Ctrl+C)` 발생 시 단순 안내 문구만 출력되고 종료되어 데이터가 저장되지 않는 문제가 있었습니다.

\- `try-except-finally` 구조를 개선하여, 예외 상황이나 강제 종료 시에도 `finally` 블록을 통해 `game.save()`가 호출되도록 수정했습니다.

\- `game` 객체를 블록 상단에서 생성하여 예외 처리 영역에서도 접근할 수 있도록 보장했습니다.



\## 2. 테스트 시나리오 및 결과

1\. \*\*퀴즈 추가\*\*: 메뉴 `2번`을 통해 새로운 퀴즈를 입력 및 등록함.

2\. \*\*강제 종료\*\*: 메뉴 선택 대기 중 `Ctrl + C`를 입력하여 예외 발생 유도.

3\. \*\*결과 확인\*\*:

&#x20;  - `KeyboardInterrupt` 예외 포착 후 안내 메시지 출력.

&#x20;  - `finally` 블록에서 `game.save()`가 정상 실행되어 상태 저장 완료 메시지 출력 (`state.json` 갱신 확인).

4\. \*\*재실행 검증\*\*:

&#x20;  - 프로그램을 재실행(`python main.py`)한 후 `3번(퀴즈 목록)`을 확인한 결과, 강제 종료 직전에 추가했던 퀴즈가 유실되지 않고 정상적으로 로드됨을 확인 완료.
